# Johnson & Johnson Brand Asset Package

This directory records the campaign's employer-identity provenance.

A stable, crisp standalone official logo file was not exposed by the connected official-page sources, and RoleForge prohibits tracing, redrawing, or substituting a third-party logo. The campaign therefore uses a clearly typeset nominative `Johnson & Johnson | MedTech` identity in HTML and print furniture, always paired with `Candidate vision by Russell Dudek` or equivalent independent-candidate language.

Authoritative sources:

- https://www.jnj.com/
- https://www.jnjmedtech.com/en-US/

See `/brand-intelligence.md` and `/brand-tokens.css` for the complete decision record.
